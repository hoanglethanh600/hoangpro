Cài Gemini API Key trước tiên

Để Bit hỗ trợ tốt nhất — trả lời bằng các model AI Gemini và đọc thành tiếng bằng giọng Gemini TTS — bạn cần cài API key của riêng mình. Chưa có key thì chatbot chưa thể trả lời.

Bước 1: Bấm nút dưới, đăng nhập Google rồi chọn Create API key.

Bước 2: Sao chép key vừa tạo.

Bước 3: Dán vào ô bên dưới → Lưu & kiểm tra kết nối.

🔑 Lấy Gemini API key miễn phí

Khi key đang dùng hết hạn mức TTS/chat (429) hoặc bị Google từ chối, Bit sẽ tự chuyển sang key tiếp theo trong danh sách, giữ nguyên giọng Gemini và model đã chọn — bạn không cần bấm lại, không bị đổi sang giọng trình duyệt trừ khi mọi key đều hết. Dán càng nhiều key (từ các dự án Google AI Studio khác nhau) thì càng khó bị ngắt giọng giữa chừng.

🛡️ An toàn: Key chỉ lưu trong trình duyệt của bạn (localStorage), chỉ gửi thẳng tới Google khi Bit trả lời/đọc — không gửi cho admin, không dán key vào ô chat hay chia sẻ cho người khác.
